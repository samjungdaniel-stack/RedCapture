# 빨간버튼 캡처 (Galaxy용)

화면 오른쪽에 떠 있는 빨간 버튼을 누르면 현재 화면을 캡처해서 아래 이름으로 저장합니다.

```
앱이름-세부카테고리-연월일시분초.png
예) 카카오톡-Chat-20261118213045.png
    설정-기본-20261118213102.png
```

- **앱이름**: 캡처할 때 화면에 떠 있던 앱의 이름
- **세부카테고리**: 그 앱 안의 화면(액티비티) 이름. 이름을 알 수 없으면 `기본`
- **저장 위치**: 갤러리 > 앨범 `RedCapture` (내장 메모리 `Pictures/RedCapture`)
- 버튼은 캡처 순간 잠깐 숨겨지므로 사진에 찍히지 않습니다.
- Android 11 이상 필요 (최근 Galaxy는 모두 해당)

---

## APK 만드는 방법

### 방법 A. GitHub로 자동 빌드 (PC 설치 불필요)
1. github.com에서 새 저장소(repository)를 만들고 이 폴더의 파일을 모두 업로드합니다.
   (`.github` 폴더도 꼭 함께 올리세요.)
2. 저장소의 **Actions** 탭 → `Build APK`가 자동 실행됨 (3~5분)
3. 완료된 실행을 눌러 아래 **Artifacts**에서 `RedCapture-apk`를 내려받아 압축 해제 → `app-debug.apk`

### 방법 B. Android Studio
1. Android Studio → Open → 이 폴더 선택
2. 상단 메뉴 Build → Build App Bundle(s) / APK(s) → Build APK(s)

## 휴대폰에 설치·설정
1. `app-debug.apk`를 휴대폰으로 옮겨 실행 → "출처를 알 수 없는 앱" 설치 허용
2. 앱 실행 → **접근성 설정 열기** → 설치된 앱 → 빨간버튼 캡처 → 켜기
3. 스위치가 회색으로 막혀 있으면: 앱 정보 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 2번 다시
   (Play 스토어 밖에서 설치한 앱에 Android 13+가 거는 보호 장치입니다)

## 참고
- 1초 안에 연속으로 누르면 Android가 캡처를 막습니다. 1초 정도 간격을 두세요.
- 은행·보안 앱 등 캡처 금지 화면은 검게 저장되거나 실패할 수 있습니다.
- 캡처한 이미지는 휴대폰 안에만 저장되고, 앱은 인터넷 권한이 없어 외부로 보내지 않습니다.
